# Průzkum CA - jak dnes spravuje WordPress weby (2026-11-06)

Cesty v CA relativně k repu CA, v pluginu k `D:\xampp\htdocs\_uxs-wt-csp\`.

## 1. Typ webu
- `sites.type ENUM('wordpress','generic')` default wordpress (`migrations/002_site_types_and_health.php`), `sites.protocol ENUM('legacy','uxstudio')` (`migrations/075_site_plugin_protocol.php`), `sites.wp_version`, `acf_active`, `enabled_modules` (JSON, žádná migrace ho nezakládá, jen DOCS.md:240), `api_key_encrypted`, `cron_use_wp_default`.
- Párování: `ConnectController::receive()` povoluje `site_type` jen wordpress|generic; `challengeNode()` zkouší `/ping` v legacy a uxstudio a nastaví `protocol`.
- `core/WebPing.php` (`probe()`, `extractMeta()`) heuristika WP. Audit už Joomlu zná: `core/Audit/CmsRegistry.php`, `CmsFingerprint.php`, `core/CmsEol.php` (`cms_eol_cycles` má `joomla/*`).
- `models/Site.php`: `isWordPress()`, `supportsContent()`, `typeLabel()`, `hasModule()`, `getClient()`, `testConnection()`, `wpCronUrl()`, `hydrate()/create()/update()`.
- Natvrdo WP: `core/ApiClient.php` (base `/wp-json/uxstudio/v1/content-sync/node`, legacy `/wp-json/wpextended/v1/content-sync`); wp-admin odkazy v `SsoController.php`, `AiRewriterController:241`, `AiAgentController:911`, `core/AiTools.php:482`, `DashboardController:352`, `core/DnsChangeMailer.php:403`, `views/partials/sites_table.php:529`, `views/dashboard/site.php:84`, `views/settings/sso.php`, `SsoConfig.php:337`, `SsoSettingsController:108`; `SsoConfig::WP_ROLES`; `type === 'wordpress'` v AiChat/AiAgent/AiRewriter/AiImage/PostController:799/SsoController/SiteController 660-991/CronController:759, `core/AiTools.php`, `core/IpBanPusher.php`, `core/MonitorOverview.php:65`, `views/sites/_sso_section.php`, `_dns_section.php`, `form.php`, `views/posts/*`, `sidebar.php:106`, `layout.php:20`, `index.php:1085` `$wpOnlyPages`; cron `site_cron_runs.source ENUM('wp_default','custom')`; `packages.type ENUM('plugin','theme')`; `core/VulnerabilityFeed.php` jen Wordfence, `VulnerabilityLookup` typy plugin|theme|core, `AuditScanner:923`.

## 2. Protokol
- Párování: plugin POST z prohlížeče na `{CA}/?page=connect_site` (`site_url, site_name, api_key, timestamp ±600 s, site_type, return_url, signature=hmac_sha256(site_url|site_name|timestamp|site_type, api_key)`), plugin `includes/Core/Onboarding/CentralApp.php`. CA `ConnectController` → challenge podepsaným `/ping`, `pending_connect` v session, `Site::create`, oprávnění `core/ConnectPolicy::decide()`. Klíč AES-256-GCM v `sites.api_key_encrypted` (`core/Encryption.php`).
- CA→web `core/HmacAuth.php`: hlavičky `X-Content-Sync-Signature/-Timestamp/-Nonce/-Version`; uxstudio `METHOD\nURL\nTS\nNONCE\nsha256(body)`, okno 300 s. Web ověřuje `Modules/ContentSync/HmacAuth::verify_request()`, `NodeController::verify()`.
- Web→CA stejný podpis s nonce, identifikace `site_url` → `Site::findByUrl`, `HmacAuth::verify()`, `core/HmacNonce` (`hmac_nonces`).
- Routy webu (`NodeController.php`, `NodeHealth.php`): `ping`, obsah (`posts`, `categories`, `taxonomies`, `media`, `acf/field-groups`), zdraví `updates`, `php-errors`, `pagespeed`, `email-health`, `security-monitor`, `vulnerabilities`, `guide`, `service-requests`, `email-log`; `ip-bans`, `ip-bans/sync` (`core/IpBanPusher.php`), `bot-throttle/bans?since=`; `cron-control`; `packages/*` (`NodePackages.php`); SSO `sso/issue`, `sso/revoke-all`, `sso/sync-operators` (`?uxstudio-sso=TOKEN`, `SsoRedeemer`, `SsoTokenStore`, `SsoOperatorMapper`).
- Pozor: UX Studio ping vrací jen `site, acf_active, post_types, authors`, ale CA čeká `wp_version, php_version, enabled_modules, capabilities` (`Site::testConnection`, `SiteMetaCache`). Endpointy `top-bar`, `admin-notices`, `push-notifications/*`, `vulnerabilities/scan` u uxstudio vrací 404.
- Endpointy CA volané webem: `turnstile_provision`, `security_api&action=inventory` (→ `site_software`), `ticket_api`, `dns_manage`, `seo_ai_api`, `site_config`, `instagram_api`, `reviews_api`, `google_places_proxy`, `heartbeat`.

## 5. Doporučený řez
Rozhraní `CmsConnector`/adaptér: transport + podpis společný, adaptér dodá base URL, URL buildery (`adminUrl`, `editUrl`, `cronUrl`), role pro SSO, normalizaci pingu a zdraví. Továrna `Site::getClient()` (dnes ~25 přímých `new ApiClient`). `Site::supports($site, cap)` místo `isWordPress()`. Migrace: `type` + `joomla`, `protocol` + `uxjoomla`, `cms_version`. `site_software.software_type` + joomla typy, `packages.type` + `joomla_extension` (čtení XML manifestu). Cron Joomla Scheduler webcron.
